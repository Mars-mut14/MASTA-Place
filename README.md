# MASTA's Place

## About the Project

MASTA's Place is a responsive accommodation website developed as part of an Information Technology Software Development project.

The website provides visitors with information about MASTA's Place, including the accommodation's rooms, facilities, images, contact information and booking options.

The main purpose of the website is to provide users with a simple, attractive and user-friendly way to explore the accommodation and view the available rooms.

---

## Project Objectives

The objectives of the MASTA's Place website are to:

- Create a professional accommodation website.
- Provide clear information about the accommodation.
- Display available rooms and their prices.
- Allow users to view photographs through a gallery.
- Provide contact and booking information.
- Create an easy-to-use navigation system.
- Apply CSS styling to improve the appearance of the website.
- Make the website responsive on desktop, tablet and mobile devices.
- Demonstrate the use of HTML and CSS in developing a functional website.

---

## Website Features

The website includes the following features:

### 1. Home Page

The Home page introduces visitors to MASTA's Place and provides an overview of the accommodation.

### 2. About Us

The About Us page provides information about MASTA's Place and its purpose.

### 3. Our Rooms

The Rooms page displays the available accommodation options.

The rooms currently include:

- Deluxe Room – R1,000 per night
- Standard Room – R800 per night
- Family Room – R1,500 per night

Each room includes an image, room information, price and a booking option.

### 4. Gallery

The Gallery page allows visitors to view images of MASTA's Place and its facilities.

The gallery includes images of:

- The exterior of the accommodation
- Deluxe bedroom
- Standard bedroom
- Living room
- Kitchen
- Bathroom

### 5. Contact Page

The Contact page provides visitors with contact and booking information, including:

- Telephone number
- Email address
- Physical address
- Booking form
- Special request section

### 6. Responsive Design

The website uses CSS media queries to allow the layout to adjust to different screen sizes.

The website is designed to support:

- Desktop computers
- Tablets
- Mobile phones
